# analisis-multivariat-tingkat-tekanan-akademik-mahasiswa
Proyek ini menganalisis faktor-faktor yang memengaruhi tekanan akademik mahasiswa menggunakan metode Analisis Diskriminan (LDA), Random Forest, dan Regresi Ordinal. Dataset yang digunakan mencakup aspek demografi, akademik, gaya hidup, dan kondisi finansial mahasiswa.
